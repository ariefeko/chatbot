## 3.3 AI Workflow

### Objective

AI Workflow defines how the chatbot processes user questions, retrieves trusted Lactoclub knowledge, generates responses, and escalates cases when needed.

The workflow must ensure every answer is accurate, traceable, and aligned with business rules.

---

### Main Conversation Flow

```text
User Question
      ↓
Chatbot Widget
      ↓
AI Backend API
      ↓
Intent Detection
      ↓
Retrieve Relevant Knowledge
      ↓
Build Prompt Context
      ↓
Call AI Model
      ↓
Validate Response
      ↓
Return Final Answer
      ↓
Log Conversation
```

---

### RAG Workflow

```text
User Question
      ↓
Search Lactoclub Knowledge Base
      ↓
Retrieve Relevant Articles / FAQ / Product Data
      ↓
Rank Best Matches
      ↓
Inject Context into Prompt
      ↓
Generate Grounded Answer
```

The chatbot should answer using official Lactoclub content, not only the model’s general knowledge.

---

### Business Workflow

For business-related requests, the chatbot may call internal systems.

Examples:

```text
Check reward points
Find product information
Open membership guide
Create customer service request
Escalate to human agent
```

The AI model should not directly access business systems. All business actions must be controlled by the AI Orchestrator.

---

### Escalation Workflow

The chatbot should escalate when:

- Confidence is low
- User asks medical or sensitive questions
- Product complaint is detected
- Membership or reward issue requires human support
- User explicitly asks for Customer Service

```text
AI Cannot Safely Answer
      ↓
Collect Required Information
      ↓
Create Ticket / Handoff
      ↓
Customer Service Follow-up
```

---

### Workflow Principles

- Measure confidence before answering
- Use official knowledge sources
- Avoid unsupported claims
- Ask clarification when intent is unclear
- Validate response before sending
- Log every interaction for audit and improvement
