## 3.1 AI Model

### Objective

The AI model acts as the intelligence layer of the chatbot. It understands user intent, processes retrieved Lactoclub knowledge, and generates natural language responses for website users.

The model must prioritize accuracy, safety, and consistency over creativity.

---

### AI Model Architecture

```text
                User Question
                       │
                       ▼
               AI Orchestrator
                       │
        ┌──────────────┼──────────────┐
        │              │              │
        ▼              ▼              ▼
 Conversation      RAG Engine     Business APIs
    Memory             │              │
                       ▼              ▼
              Retrieved Context   API Results
                       │              │
                       └──────┬───────┘
                              ▼
                         AI Model
                              │
                              ▼
                     Generated Response
                              │
                              ▼
                     Response Validation
                              │
                              ▼
                         Final Answer
```

The AI model should not work alone. It should receive controlled context from the AI Orchestrator before generating a response.

---

### Model Principles

The AI model should:

- Support Bahasa Indonesia and English
- Understand multi-turn conversations
- Support Retrieval-Augmented Generation (RAG)
- Support tool/function calling
- Produce structured output when needed
- Minimize hallucination
- Be replaceable without major architecture changes

The AI model should not store business logic. Business rules must be handled by the AI Orchestrator or backend services.

---

| Capability | Requirement |
|---|---|
| Natural conversation | Required |

| Reasoning | High |
| RAG support | Required |
| Tool calling | Required |
| Structured JSON output | Required |
| Response speed | High |
| Cost efficiency | Medium |
| Enterprise reliability | High |

---

### Context Strategy

The AI model should not rely only on general training data.

Each response should be generated using:

```text
System instruction
→ Business rules
→ Conversation history
→ Retrieved Lactoclub knowledge
→ API results
→ User question
```

This ensures answers are grounded in official Lactoclub content and relevant business data.

---

### Hallucination Control

The model should:

- Answer based on official knowledge sources
- Avoid unsupported claims
- Ask clarification questions when needed
- Escalate sensitive questions to Customer Service
- Avoid giving medical diagnosis
- Cite or reference official content when possible

---

### Recommended Model Strategy

The vendor should propose:

- Primary LLM
- Fallback LLM
- Embedding model for RAG
- Context window configuration
- Cost and latency estimation
- Evaluation result
- Model replacement strategy

The architecture should avoid dependency on a single AI provider.
